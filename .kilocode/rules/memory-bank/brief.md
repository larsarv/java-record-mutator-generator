# Java Record Mutator Generator project Brief

The JRMG project is a Java annotation processor that generates builders called mutator and constructors for Java
records.
They enables developers to create chainable operations to modify nested record fields without resorting to complex
workarounds or manual builder patterns.
The project also provides mutators and constructors for a number of collection types, such as lists and sets and maps.

The goal is to provide a simple way for developrs to work with imutable data models.
